# Japanese Study

Este es un repositorio personal dedicado al aprendizaje autodidacta del idioma japonés desde cero.

El proyecto reúne mis apuntes, ejercicios y prácticas de estudio, documentando progresivamente mi aprendizaje del japonés, desde sus sistemas de escritura hasta la gramática y el vocabulario.

## Contenido

| Carpeta       | Descripción                                                                           |
| :------------ | :------------------------------------------------------------------------------------ |
| `0_Hiragana/` | Estudio del silabario hiragana, reconocimiento de caracteres y ejercicios de lectura. |
| `1_Katakana/` | Estudio del silabario katakana y práctica de reconocimiento.                          |
| `2_Kanji/`    | Aprendizaje de kanji, significados, lecturas y escritura.                             |

## Objetivos

- [ ] Aprender y reconocer los caracteres katakana.
- [ ] Aprender y reconocer los 46 hiragana básicos.
- [ ] Comprender las diferencias entre hiragana, katakana y kanji.
- [ ] Ampliar progresivamente el vocabulario japonés.
- [ ] Aprender las estructuras gramaticales fundamentales.
- [ ] Mejorar la lectura y comprensión del japonés.

## Métodos de estudio

El aprendizaje se desarrolla mediante el estudio individual, la repetición y la práctica constante.

Los métodos de trabajo incluyen:

**1. Conversión de sistemas de escritura**
- Hiragana → Romaji.
- Katakana → Romaji.
- Kanji → Romaji.
- Romaji → Hiragana.
- Romaji → Katakana.
- Romaji → Kanji.

Cuando no recuerde un carácter durante los ejercicios, utilizaré `-` para indicar que desconozco la respuesta.

**2. Reconocimiento y memorización**
- Identificación de caracteres presentados aleatoriamente.
- Reconocimiento de caracteres similares.
- Práctica de lectura sin consultar tablas de referencia.
- Repetición de caracteres que presenten mayor dificultad.

**3. Vocabulario y lectura**
- Asociación de palabras japonesas con sus significados.
- Lectura de palabras y oraciones sencillas.
- Identificación de hiragana, katakana y kanji dentro de una misma oración.

**4. Evaluación**
- Ejercicios aleatorios para comprobar el reconocimiento.
- Repaso de errores anteriores.
- Pruebas de memoria sin consultar apuntes.
